# StudentAgeEditorPlus

> StudentAge（学生时代）MOD 编辑器增强插件（BepInEx）
>
> 纯作者侧编辑器增强，主打可视化编辑体验与剧情图（Beta），详见 [修复说明.md](修复说明.md)。

## 安装

**方式一：创意工坊订阅（推荐）**

1. 在 Steam 创意工坊订阅 EditorPlus 及其右侧「必需物品」（学生时代 MOD 管理器）；
2. 运行 MOD 管理器，一键部署 BepInEx 环境并接入工坊插件；
3. 启动游戏，进入创意工坊编辑器即可使用全部增强。

**方式二：手动安装**

1. 安装 BepInEx 5；
2. 从 [Releases](https://github.com/white12666/StudentAgeEditorPlus/releases) 下载并解压 `StudentAgeEditorPlus-v*.zip` 到游戏根目录；
3. 启动游戏。

EditorPlus 只面向 Mod 作者，生成的原生配置不要求玩家安装本插件。

## 从源码构建

```powershell
dotnet build .\StudentAgeEditorPlus.csproj -c Release
```

本地开发构建只部署作者端：

- `BepInEx/plugins/StudentAgeEditorPlus/StudentAgeEditorPlus.dll`。

只构建、不部署到当前游戏：

```powershell
dotnet build .\StudentAgeEditorPlus.csproj -c Release -p:DeployToGame=false
```

## 可视化编辑体验

### 编辑背景音乐开关（0.4.21）

作品操作区、普通配置、人物、剧情和结局编辑页新增「喇叭＋BGM」按钮，剧情图顶部也有同步入口。
声波表示开启，斜杠表示关闭，点击时有短过渡动画；所有入口共享偏好并在下次启动保留。
仅关闭编辑环境 BGM，不改变按钮音效、语音、游戏音量或作品配置。

完整剧情预览和「预览本句」仍可播放剧情指定的音乐，实际播放时显示「试听中」；
没有指定音乐的预览不会把原本关闭的背景音乐打开。退出预览恢复编辑偏好，离开编辑器不影响正常游戏。
新导入的 BGM 请先保存音频配置，再使用剧情预览；本版不提供音乐选择列表的独立试听按钮。

离线逻辑测试：`dotnet run --project .\Tests\EditorAudioTests\EditorAudioTests.csproj -c Release`。
0.4.21 已完成 1280×720 / 1920×1080 实机回归，各通过 27 项检查；
测试范围与声音验证限制见 [验证记录](Tests/EditorAudioTests/QA-2026-09-17.md)。

0.4.22 将「创作 Mod」页的 BGM 控件独立放在「返回」左侧，不再加入原按钮横排；
返回、打开目录、本地保存、上传以及其它插件已有按钮的位置与尺寸不因 BGM 控件改变。
已在 1024×656、1280×720、1920×1080 各通过 31 项实机布局检查，
详见 [布局回归记录](Tests/EditorAudioLayoutGameTests/README.md)。

0.4.33 修正剧情、结局编辑页右列「保存」与 BGM 同排时，低分辨率下「保存」被挤窄甚至挤出屏幕的问题：
「保存」至少保留这一行一半的宽度，BGM 只用剩下的空间，放不下文字时只显示喇叭图标（悬停仍有说明）。
1920×1080 下外观不变；剧情编辑页已在 1024×656、1280×720、1920×1080 实机检查，
见 [StudentAge Harness 场景包](Tests/HarnessScenarios/README.md)。

0.4.23 起剧情图保存前的版本改存到作者本机 `BepInEx/config/StudentAgeEditorPlus/StoryGraphBackups/`，
不再写进作品目录，避免随作品上传；旧版本留在作品目录里的 `.storygraph.bak` 会在下次保存时移过去保留，不会删除。
剧情图保存前检查与图上标注改用同一判定：正文播完会进入选项界面的对话，游戏不读取它的
`nextTalk`、`nextTalk2` 和 `check`，这些位置残留的失效编号不再阻止保存；对话自带小游戏时仍照常检查。

EditorPlus 让编辑器从"数字堆砌的表单"变成"看得见"的创作台：

- **图片预览**：CG / 背景 / 物品 / 书籍 / 珍贵记忆 / 行动 / 状态 / 企鹅空间动态 / 头像等编辑器全部显示图片预览，换图保存后预览即时刷新；
- **动作指令悬浮翻译**：`1,3004,300` 这类数字串悬停即显示为「小明：横向移动（向右 300、用时 0.5 秒）」，屏幕效果的 20 余种含义同样可悬停查看；
- **移动与表情示意**：右侧人物小舞台显示累计目标位置——人物会走到哪里一眼可见；`3000` 表情/姿势也会实时显示，不再永远使用默认脸；
- **人物预览 9 位置**：对话编辑器每个方位 3 个位置全部可用（全屏最多 9 人），点击 + 添加入场人物，点击已有位置可替换或清除；
- **「预览本句」**：从任意一句开始播放剧情预览，未保存的改动也能立即预览，调试长事件不再每次从头逐句点击；
- **数字字段可读化**：企鹅空间的发布者、点赞、评论、背景音乐等字段以灰字翻译为人名与说明，不用反复查表。

以上均只影响编辑器中的显示与预览，不会修改数据，也不改变玩家实际剧情逻辑。

上述各项的详细说明见 [修复说明.md](修复说明.md) 第 1~4 节。

## 剧情图（Beta）：事件分支总览与可视化编辑

事件对话编辑器工具栏新增「剧情图」入口：点击后在编辑器上覆盖一张**从左到右的节点图**，对话与选项分别显示为节点、跳转关系画成连线，入口在左、结束节点在右，整个事件的分支走向一眼看全。剧情图同时提供只读的**总览模式**和独立的**可视化编辑模式**。

> 剧情图及其可视化编辑目前为 **Beta**：核心路径可用，界面与行为可能随版本调整，欢迎反馈。

### 总览模式（只读）

- **自动折叠链段**：没有分支的连续对话自动收成一块「N 句对话」链段块，单击展开看每句内容、再单击收回，长对白不再刷屏；
- **未使用配置折叠区**：写了但没有任何节点引用到的配置集中收进底部折叠区，方便排查废案；
- **打开即定位**：打开剧情图时自动居中到当前正在编辑的那句对话；双击对话节点会在原事件编辑器中选中对应句，剧情图保持打开，可并排对照；
- **悬停链路高亮**：鼠标悬停节点时高亮它的上下游链路，并浮出完整内容，不用点进去就能核对文本；
- **画布操作**：滚轮缩放、拖拽平移，右下角小地图总览全局，顶部搜索框按内容定位节点。

### 编辑模式

点击「编辑剧情」进入独立草稿，不会边拖线边改动原事件编辑器或磁盘文件：

- 从对话的「下一句 / 备用 / 选项」端口或选项的「结果 / 备用」端口拖线即可改接；
- 拖到画布空白处会自动分配未占用编号、新建兼容节点并完成连接；末句还可一键生成原生「确定」结尾选项；
- 支持新增、复制、二次确认删除、右击端口逐条断线/整组清空、`Ctrl+Z` / `Ctrl+Y`（或 `Ctrl+Shift+Z`）撤销重做和 `Ctrl+S` 保存；
- 删除节点、分组或注释框时保留幸存节点和当前视野；需要压缩空隙时再显式使用「自动整理」；
- 保存前按游戏真实分支规则预检：缺失目标、会卡死的自动循环、小游戏出口、危险性别槽、演出越界等；
- 新编号同时避开草稿、完整 Mod JSON 和内置配置；删除前从其它事件入口遍历共享剧情路径；
- 事件级选项、`maxoptions` 随机候选和事件小游戏覆盖关系也会进入总览；共享选项会显式标记；
- 多性别槽位不会被普通拖线静默覆盖；复杂字段和完整正文仍可回原表单编辑；
- 安装独立 StudentAgeLatex 时，「基础」页正文框下会实时预览 `$` 行内公式与 `$$` 二维公式；未安装时该区域自动隐藏，剧情图其它功能不受影响。

### 数据安全与兼容性

- 所有操作先进入深拷贝草稿；保存通过可恢复事务更新 `TalkCfg.json` 与 `OptionCfg.json`，强退/断电留下的未完成事务会在下次事件加载前自动恢复；保存前的最近一个版本备份在作者本机 `BepInEx/config/StudentAgeEditorPlus/StoryGraphBackups/`，不在作品目录内，不会随作品上传；检测到其它工具并发修改文件时会取消提交；
- 查看模式完全只读；只有明确进入编辑模式并点击「保存」后才会写入游戏原生字段，不增加玩家端无法识别的新剧情格式——生成的 mod 玩家可直接游玩，**无需安装本插件**；
- 保存后「预览本句」立即使用最新内容；但本局游戏内正式触发该事件仍使用启动时合并的旧数据，需重启游戏后生效（这是游戏只在启动时合并 Mod 配置的原生行为，原版编辑器同样如此）。

详细交互、限制和保存策略见 [修复说明.md](修复说明.md#5-剧情图事件分支可视化总览与节点编辑-已添加-beta)。

## 退出前的未保存提醒（0.4.24）

原版事件对话、通用配置、人物和结局编辑页点「退出」会直接关闭，没保存的修改全部丢失。
现在退出时如果有未保存的修改，会先弹出提醒并列出改动数量，可选「保存并退出」「不保存退出」「继续编辑」。
「保存并退出」等写盘完成后才关闭；保存被其它检查拦下或写盘失败时页面保持打开，修改不会丢。
只点了「新增」、什么都没填的空白记录不算修改；编号为 0 的记录会额外提示原版保存时将被丢弃。剧情图保存成功后同样视为已保存。
0.4.25 起提醒直接使用游戏原版确认框（同样的面板、遮罩、动画和按钮），只在按钮行里多加一个「不保存退出」；右键等同「继续编辑」。
0.4.26 起通用配置页在提醒里显示与创作页列表相同的中文名称（例如「送礼触发事件」），不再显示配置类型名。

同时修复原版把本体对话、选项和「浏览事件」加入的本体事件按原对象放进编辑列表的问题：
以前没保存就退出，重新打开仍能看到修改，像是保存过，重启游戏才消失；现在编辑页使用副本，未保存的修改不会再改动本局游戏里的原配置。

作品上传页和直接关闭游戏窗口不在提醒范围内。详细说明见 [修复说明.md](修复说明.md) 第 14 节。
离线逻辑测试：`dotnet run --project .\Tests\UnsavedEditTests\UnsavedEditTests.csproj -c Release`。

## 剧情编辑页的撤销与快捷键（0.4.30）

原版事件对话编辑页左上角现在是「+ 新建 / 撤销 / 重做」，不挤占右侧按钮列。
普通台词和 CG 台词点入时不再自动全选，仍可用 Ctrl+A 主动全选。

- Ctrl+Z 撤销；Ctrl+Y 或 Ctrl+Shift+Z 重做。正在输入时误删整段，不必先点到别处就能恢复。
- 同一输入框的一次连续输入合为一步；停顿超过约 1 秒、移动光标/选区、切换字段或台词后分开记录。
- 覆盖正文、字段、人物/背景/音频修改、新增/删除对话及已「完成」的选项修改。选择弹窗中尚未提交的内容不归这一页历史管理。
- Ctrl+S 先提交当前输入，再走原保存按钮及其它插件的检查。普通保存不清空撤销记录；撤销只改当前草稿，不改已保存文件。
- 剧情图保留自己的快捷键和历史；每次从剧情图成功保存回表单，在表单里记作一步整体修改。
- 每个打开的事件最多保留 100 步，关闭重开清空。别的弹窗或剧情图打开时，表单快捷键不响应；中文输入法组合期间不触发。

此处未增加 Ctrl+F、按词删除或其它 Word 排版快捷键。离线测试：
`dotnet run --project .\Tests\EditorHistoryTests\EditorHistoryTests.csproj -c Release`。
实机回归见 `Tests/EditorHistoryGameTests/README.md`。

0.4.32 补齐 Windows 快速组合键的全局 KeyDown 路径，避免输入框失焦后偶发漏掉快捷键；
同时修复普通正文与 CG 正文切换时隐藏框仍保留旧文字的问题。
已通过 Windows 前台键盘驱动和微软拼音候选输入验证，详见 `Tests/EditorHistoryGameTests/KEYBOARD_QA_20260927.md`。

## 送礼剧情绑定

在「送礼触发事件」选中记录后，点击底部「绑定送礼剧情…」，按 NPC 添加绑定，搜索剧情标题或台词，确认首句后自动回填。默认男女主共用，也支持分别设置入口和单一性别不触发。移动或移除 NPC 时，剧情与物品消失设置一起变化。

「应用绑定」只回填表单，随后点击原表单「保存」才写入 `GiftEvtCfg.json`；取消不改原数据。保留高级 ID 输入，保存时检查缺失入口与错位数据。具体步骤见《修复说明》第 8 节。当前不包含从送礼页直接新建剧情的功能，请先在事件编辑器写好并保存。

0.4.16 起，上方 NPC ID 整格清空会真正清除 NPC、对白和物品设置；手动删除或重排 NPC 时，已有设置按 NPC 身份一起变化。重新添加已删除的 NPC 不会恢复旧绑定。对话 ID 和类型标记也支持清空，非法输入会提示并恢复原值。

绑定窗口允许移除全部 NPC，再「应用绑定 → 保存」，将此规则置为不触发状态；仍保留 NPC 却没有有效对白的记录不能保存。「取消」只放弃窗口内的修改，不会撤销打开窗口之前已提交到上方表单的输入。

0.4.17 起，红点提示和单 NPC 的类型标记沿用原版 Dropdown 的选中、标题更新和自动收起顺序，不再在选取回调里关闭控件并重绘整张表单。切换记录按实际值恢复选中项；多 NPC 的类型列表仍可手填，原生物品下拉不受接管。

送礼绑定的独立逻辑回归（不启动游戏）：

```powershell
dotnet run --project .\Tests\GiftBindingTests\GiftBindingTests.csproj -c Release
```

覆盖草稿隔离、男女主入口、NPC 顺序、旧数据保护和本作品剧情读取；界面显示、实际点击与保存重开仍需游戏内测试。

本地 Harness 场景为 `../StudentAgeDndEditor/tools/run-harness.ps1 -Scenario editorplus-gift-binding`。0.4.17 已在 1920×1080、1280×720 各通过 196 步真实游戏验证，包含下拉反复选取/单勾选/自动收起、保存值一致、记录切换，以及表单清空/重排同步、空绑定保存重开和缺失首句拒绝；同轮各通过 52 步普通剧情回归。使用独立临时作品，不触碰玩家存档。

## 考试同学排名配置

成绩调整面向考试榜中的“同学条目”，入口不在「NPC人物」页面。打开作品后选择对应年级：

- 「考试同学（小学）」；
- 「考试同学（初中）」；
- 「考试同学（高中文科）」；
- 「考试同学（高中理科）」。

点击新增后，可直接从下拉列表选择要调整的同学；EditorPlus 会自动带出其姓名、关联人物、性别、原权重和条件。作者通常只需调整「排名倾向权重」或「生效条件」。普通同学不需要 PersonCfg，`关联剧情人物` 保持 0 即可。

NPC 人物页原生的 `examRank` 字段仍保留给高级剧情人物使用，但已明确标为「剧情人物排名（高级）」；点击旁边的「同学入口」只会给出一条简短路径提示，不再弹出内部字段长说明。

权重不是直接分数：它只影响同学在当前排名段中的先后倾向，最终分数仍由实际名次生成。保存结果是原生 `Classmate*Cfg.json`，普通玩家无需安装 EditorPlus。详细限制和剧情条件示例见《修复说明》。
